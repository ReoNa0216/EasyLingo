## 依赖审查

前端依赖已加入 npm 锁文件，`npm audit` 当前无已知漏洞。Rust 依赖从四月锁定版本更新至 Tauri 2 稳定系列。RustSec 扫描仍报告：

- `libsqlite3-sys 0.30.1` / RUSTSEC-2026-0459：上游 SQLx 0.8 暂未支持修复版本。触发条件是打开由不可信方提供的数据库及页大小不匹配的 WAL 文件。本工具的交换入口为结构化 JSON；应使用自己管理的数据库目录，不接收第三方原始 `.db`/`-wal` 文件。此项保留为提交决策所需的已知依赖风险，不计为已修复。
- `rsa 0.9.10` / RUSTSEC-2023-0071：锁文件含 SQLx 可选 MySQL 依赖，Windows x64 与 macOS ARM64 的 `cargo tree -i rsa --target ...` 均显示没有可达依赖，此库未进入两个目标的实际构建。
- `glib` 告警涉及 Linux，非本次 Windows/macOS 构建；其余停止维护的传递依赖逐项记录在扫描输出中。

参考：[PDF.js 公告](https://github.com/mozilla/pdf.js/security/advisories/GHSA-wgrm-67xf-hhpq)、[SQLite 公告](https://rustsec.org/advisories/RUSTSEC-2026-0459.html)、[Tauri CSP](https://v2.tauri.app/security/csp/)。
