# EasyLingo 提交审计

审计日期：2026-11-16。基线：`e5aa5c1`，GitHub 仓库 `ReoNa0216/EasyLingo`。目标：清华大学语言中心资源共享平台提交版；开发者陈挚，开发单位清华大学语言教学中心。

## 范围和基线

审计覆盖前端全部功能入口、SQLite 读写与迁移、JSON 备份、文件解析、新闻抓取、AI 请求与题目渲染、复习和统计、Tauri 权限、依赖、README、发布工作流与已有 Releases。基线无未提交修改；远程 main 与本地一致；已有 v2.0.0 Windows/macOS 安装包；无公开 issue 或 PR。既有 Release 无更新说明，仓库声明 MIT 但未附 LICENSE。

对当前跟踪文本及全部分支可见的 115 个历史提交进行了常见 API 密钥、GitHub token、私钥头和云访问密钥特征扫描，未命中。旧 API 配置指南的 6 页逐页查看，账号信息已打码，密钥为遮蔽或截断显示，未见完整凭据。此检查不等同于验证任意格式凭据均不存在。

## 依赖审查

前端依赖已加入 npm 锁文件，`npm audit` 当前无已知漏洞。Rust 依赖从四月锁定版本更新至 Tauri 2 稳定系列。RustSec 扫描仍报告：

- `libsqlite3-sys 0.30.1` / RUSTSEC-2026-0459：上游 SQLx 0.8 暂未支持修复版本。触发条件是打开由不可信方提供的数据库及页大小不匹配的 WAL 文件。本工具的交换入口为结构化 JSON；应使用自己管理的数据库目录，不接收第三方原始 `.db`/`-wal` 文件。此项保留为提交决策所需的已知依赖风险，不计为已修复。
- `rsa 0.9.10` / RUSTSEC-2023-0071：锁文件含 SQLx 可选 MySQL 依赖，Windows x64 与 macOS ARM64 的 `cargo tree -i rsa --target ...` 均显示没有可达依赖，此库未进入两个目标的实际构建。
- `glib` 告警涉及 Linux，非本次 Windows/macOS 构建；其余停止维护的传递依赖逐项记录在扫描输出中。

参考：[PDF.js 公告](https://github.com/mozilla/pdf.js/security/advisories/GHSA-wgrm-67xf-hhpq)、[SQLite 公告](https://rustsec.org/advisories/RUSTSEC-2026-0459.html)、[Tauri CSP](https://v2.tauri.app/security/csp/)。

### 已修复的实际问题

1. 英语及自定义语言批量补全误用德语规则；自定义要求在部分重试路径丢失；自定义语法性别虽保存却未显示。统一按目标语言分派规则，保留自定义细分类；旧词性标签在显示时转换，不猜测更细的语法分类。
2. 补全按返回数组下标覆盖输入，模型乱序或缺项会把 cat、dog、bird 改成 bird、cat、bird。现在按原词匹配，日语匹配允许附加读音；未完成词条不写成成功词条，错误原因显示在结果中。
3. 提取器将坏 JSON、空结果和截断响应误报完成，材料还会静默截断到五万字符。现在保留全文、分块处理并明确记录未完成；同一新闻重试复用材料，不重复写入成功部分或覆盖手动编辑。
4. 填空曾无条件移除冠词，将 das Haus 与 ein Haus、the book 与 a book 判成相同答案；本地补题会截短短语或拼造德语干扰项。现在比较完整答案，保留冠词和大小写，本地选择题只使用同一语言的真实词条释义，题干与答案按完整词条对应。
5. 题目实际使用哪个词条与去重标记不一致，可能重复出题；不足时还会将选择题配额变成填空。现在要求并验证 entryId，按实际 ID 去重，逐题型补足；不足时说明可用题数。测试与学习记录使用测试所属语言。
6. 删除旧词条留下关联卡片，会使之后导出的备份无法恢复。删除关联内容和材料计数更新在事务内完成；失败回滚。查重比较完整学习内容，保留大小写、多义和兼类，重复内容优先保留复习等级较高的条目。
7. 切换语言后残留批量选择会删除上一个语言的词条；旧查询可能覆盖新页面；导入完成可能清掉新输入。现在固定每个任务的目标模块，切换时清除选择，忽略过期渲染，保留新的输入与导航状态。
8. 导入过程中删除材料/模块可能产生孤儿数据；复习通过侧栏离开后计时器继续运行；月末统计日期溢出造成漏月。对应操作边界及日期计算已修复。

这些测试验证软件流程、提示词分派、数据持久化和异常处理。真实付费模型生成释义、词性、例句和题目的准确率尚未做独立语料评测；本轮没有以模拟响应替代这项结论。
